# data/ — the Lakehouse snapshot

The **Ingest + Lakehouse** layers of this accelerator. Everything here is **generated by the
pipeline** (nothing to procure) and gitignored — this README is the only tracked file.

## What goes here

| Path | Contents | Automated by |
|------|----------|--------------|
| `raw/` | The generated synthetic estate — 200K transactions across 31 countries with seeded fraud patterns (cross-border, high-velocity, unusual-amount). | `pipelines/data_generation/generate_synthetic_data.py` (AMP task 2) |
| `processed/` | Cleaned, typed parquet ready for feature engineering. | `pipelines/data_pipeline/preprocess.py` (AMP task 3) |
| `transactions.db` | The SQLite estate the app and agent query — transactions + engineered features. | `pipelines/data_pipeline/feature_engineering.py` (AMP task 4) |
| `generated/` | Additional transactions produced by the agent's retraining tool / experiment lab. | `ai/agents/tools/retrain.py` via `pipelines/model_training/experiment_runner.py` |
| `pricing_cache.json` · `sample_conversations.json` | Runtime caches (live LLM pricing for the cost calculator; canned agent conversations). | `ai/agents/pricing_fetcher.py` · app runtime |

## Conventions

- **Never hand-edit or commit contents** — the whole folder regenerates from
  `python pipelines/data_generation/generate_synthetic_data.py` onward; `.gitignore` keeps
  everything but this README out of git.
- This folder stays at the **repo root** (CWD-relative contract): every session, AMP task,
  serving call, and container starts with cwd = project root and reads `data/…` relative
  paths (see [ADR-001](../docs/architecture/ADR-001-dashboard-design-system.md)).
- The schema is owned by `pipelines/data_generation/schema.py` — change it there and re-run
  the chain; consumers read column names from `models/feature_names.json`, never hardcode.

The generation step (AMP task 2) is this accelerator's Ingest — see
[`../pipelines/README.md`](../pipelines/README.md).
