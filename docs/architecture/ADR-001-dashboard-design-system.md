# ADR-001 — Keep the existing dashboard design system and root-level runtime artifacts

**Status:** accepted · **Date:** 2026-08

## Context

The Forge standard prescribes the design system documented in the template repository
(`demo-design-template/docs/architecture/DESIGN_TEMPLATE.md`) for the Serve layer, and the
template's architecture README requires any deviation from the standard stack to be recorded
as an ADR.

This accelerator predates its adoption into the Forge structure:

- The frontend (`app/frontend/`, React 19 + Tailwind + Vite) ships its own dark-themed
  design language (risk-status color coding, SHAP chart palette) that was built before the
  Forge template existed.
- The backend and pipeline scripts share a **CWD-relative contract**: every CML session,
  AMP task, and container starts with cwd = project root and reads `models/…`,
  `config/config.yaml`, and `data/transactions.db` as root-relative paths. The Dockerfile
  and `docker-compose.yml` bind-mount `data/`, `models/`, and `config/` on those same paths.

## Decision

1. Keep the dashboard's existing design system. Do **not** re-skin it to the Forge template,
   and do not copy the design-system docs into this repo — they remain canonical in
   `demo-design-template/docs/architecture/`.
2. Keep `models/`, `config/`, `data/`, `Dockerfile`, `docker-compose.yml`, and
   `requirements*.txt` at the **repo root** rather than nesting them under template layers —
   moving them would force path changes in every consumer for zero functional gain,
   violating the restructure's "only change code needed to run" rule.

## Consequences

- The Serve layer deviates from the Forge design template; a future convergence is a
  token-mapping exercise in `app/frontend/src/index.css`, not a rewrite.
- Root-level exceptions are annotated in the root `README.md` tree ("why it's at root"),
  so the structure stays self-explaining.
- `data/` and `models/` remain **gitignored** (regenerated by the pipeline tasks);
  `config/config.yaml` remains gitignored because it holds LLM credentials — only
  `config.yaml.example` ships.
